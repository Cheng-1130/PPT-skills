# PPT制作技能指南

## 一、技能概述

本项目展示基于 AI 驱动的演示文稿高效创作技能，涵盖**图文排版设计**与**文档内容智能生成PPT**两大核心能力，旨在帮助用户快速产出专业级演示文稿。

---

## 二、核心技能模块

### 模块一：图文排版设计技能

#### 1. 视觉设计基础
- **配色方案设计**：掌握色彩理论，能根据主题选择合适的配色（邻近色/对比色/互补色）
- **字体搭配原则**：标题与正文字体组合，中英文混排适配
- **留白艺术**：合理控制页面元素密度，提升可读性

#### 2. 布局排版技巧
- **网格系统应用**：建立统一的布局规范，确保视觉一致性
- **视觉层级构建**：通过大小、颜色、位置区分信息重要性
- **对齐原则**：左对齐/居中/右对齐的合理运用

#### 3. 图文融合能力
- **图片选择与处理**：高清素材筛选，尺寸比例调整
- **图标系统构建**：统一风格的图标库应用
- **图表设计**：柱状图、折线图、饼图等数据可视化呈现

---

### 模块二：文档内容生成PPT技能

#### 1. 需求分析与结构规划
- **目标受众分析**：根据受众特征调整内容深度与呈现方式
- **核心信息提取**：从原始文档提炼关键观点
- **逻辑框架构建**：支持金字塔结构、时间轴、对比型等多种框架

#### 2. AI辅助创作流程
- **智能大纲生成**：输入主题关键词，自动生成PPT结构框架
- **内容自动填充**：根据文档内容智能匹配图文素材
- **文案优化润色**：AI辅助提炼核心观点，增强说服力

#### 3. 自动化工具应用
- **文档解析工具**：支持Word/PDF/TXT等多格式文档导入
- **批量生成功能**：一键将长篇文档转换为PPT页面
- **模板匹配引擎**：根据内容类型自动推荐适配模板
